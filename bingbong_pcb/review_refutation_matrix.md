# Schematic Review Refutation Matrix

Date: 2026-06-06

Basis: KiCad 9.0.6 exported netlist `review_netlist.xml`, ERC export `review_erc.json`, BOM spreadsheet, and focused datasheet review.

## Fixed in Schematic Cleanup Passes

| Issue | Status | Current validation |
|---|---|---|
| USB D+ had `C19 = 0.1 uF` and `C20 = 22 uF` to GND | Fixed in schematic on 2026-06-06 | Current netlist no longer contains `C19` or `C20`; `/USB D+` now includes `J2.A6`, `J2.B6`, `R17.1`, and `U5.1`. PCB still needs update from schematic. |
| U3 `DIR1` tied to `+3.3V` instead of `VCCA/+1.8V` | Fixed in schematic on 2026-06-06 | Current netlist confirms U3 `DIR1` and `VCCA` are on `+1.8V`; U3 `VCCB` remains on `+3.3V`. |
| Q1 PWRKEY transistor pinout mismatch | Fixed in schematic on 2026-06-06 | Current netlist confirms `Q1.1 B -> R1`, `Q1.2 E -> GND`, and `Q1.3 C -> BG95 PWRKEY`; Q1 value/datasheet now match `SMMBT2222ALT3G`. PCB still needs update from schematic and physical pad 1/2/3 orientation signoff. |
| MCP73871 `THERM` depended on ambiguous external `TH1` path | Fixed in schematic on 2026-06-06 | Current netlist confirms `U8.5 THERM -> TH1.1 / R24.2` and `TH1.2 / R24.1 -> GND`. `TH1` is now a vertical JST-PH battery NTC connector; `R24 = 10k` is DNP and should be populated only for no-thermistor builds. PCB still needs update from schematic. |

## Confirmed Critical

| Issue | Status | Refutation result |
|---|---|---|
| `+3.3V` generated by buck from single-cell battery-backed `/SYS LOAD` | Confirmed topology risk | Not refuted unless the system intentionally shuts down before battery voltage reaches buck dropout. |

## Confirmed High / Design Risks

| Issue | Status | Refutation result |
|---|---|---|
| R1200 boost inductor `L2` under-rated | Likely confirmed | BOM says `22 uH`, `220 mA`, `1.25 ohm`. Refutable only by proving +12 V load and peak inductor current are below this margin. |
| R1200 `CE` can be driven while U1 VDD is off | Confirmed topology risk | Netlist confirms `U1 CE` from ESP32 while U1 VDD is behind Q2. Refutable only if the exact R1200 CE pin is tolerant above VDD/VIN. |
| MCP73871 configuration choices need signoff | Confirmed, not automatically wrong | `SEL`/`PROG2` low, `RPROG1=10k`, `RPROG3=10k`, `~TE` high, CE firmware-controlled. These may be intentional but need design intent documented. |
| BG95 VBAT current/UVLO margin | Needs electrical validation | Netlist is correct. This is not a wiring error; it needs battery current, dropout, UVLO, and layout impedance analysis. |
| SIM implementation incomplete | Confirmed as design-quality issue | Core SIM wiring is correct; remaining concerns are missing USIM_VDD bypass, VDD ESD, reserved passives, and ESD BOM/schematic mismatch. |

| Issue | Status | Refutation result |
|---|---|---|

## Refuted Earlier False Positives

- BG95 power and GND are connected correctly.
- BG95 main antenna is on U2 pin 60, not W_DISABLE.
- BG95 main UART pins 34/35 are used.
- SIM is connected to real USIM pins 43-47.
- MCP73871 IN/OUT/VBAT/VSS/EP are not crossed.
- USB-C SuperSpeed/SBU pins are no-connect, not shorted to power/ground.
- U3 level-shifter power pins are not swapped.
